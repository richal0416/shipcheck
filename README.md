# ShipCheck

ShipCheck is a release-readiness app for Jira, built with Atlassian Forge for the Atlassian Codegeist 2026 hackathon.

For a Jira version you choose, ShipCheck shows a readiness score, the unresolved blockers, unassigned work, stale items, and whether the Confluence release notes exist — plus a built-in Rovo agent that answers questions like "What is blocking the 2.4 release?".
